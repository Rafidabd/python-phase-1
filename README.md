# Learning Python, one project at a time

This is where I started keeping my Python work. The older folders are mostly day-by-day practice: loops, functions, strings, files, JSON, recursion, and whatever else I was trying to understand at the time.

Some of those files are tiny. Some have awkward names. I've kept them because they show what I was actually working on before I began building larger projects.

## Projects that grew out of this repository

| Project | What I built | Where to find it |
| --- | --- | --- |
| **Student Performance Tracker** | A CLI that manages student records, calculates rankings, and generates charts and CSV reports. | [Standalone repository](https://github.com/Rafidabd/student-performance-tracker) |
| **Expense Tracker CLI** | A local expense tracker with basic validation, category summaries, and JSON storage. | [Standalone repository](https://github.com/Rafidabd/expense-tracker-cli) |
| **Bangladesh Academic Analytics System** | A larger project about academic performance, trends, and student-level insights, built with Python and Flask. | [Development snapshot](academics_analytics_system/) |

The two smaller projects started in [`day13_Mini_Projects/`](day13_Mini_Projects/). I've since moved their project-specific Git histories into separate repositories, so it's easier to look at each one on its own. I left the original folders here as part of the archive.

**About Academic Analytics:** This repository has an older snapshot, not all of my current local changes. I'm keeping its code and documentation as they are until the next development milestone is ready.

## How the folders are organized

- `day01_basics/` to `day06_ strings/`: early Python practice, including conditions, loops, functions, collections, and strings.
- `day08_file_handling/` to `day11_combined_file_handling/`: reading, writing, and processing text, CSV, and JSON files.
- `day12_recursion/`: recursion exercises.
- `day13_Mini_Projects/`: my first larger CLI projects.
- `academics_analytics_system/`: my ongoing academic analytics work.

I didn't try to turn every exercise into a polished project. Most of them are just practice files, and that's how I want to present them.

## If you want to try the projects

The standalone repositories are the best place to start. They have the updated setup instructions and their own READMEs:

- [Student Performance Tracker — setup, demo, and charts](https://github.com/Rafidabd/student-performance-tracker)
- [Expense Tracker CLI — setup and screenshots](https://github.com/Rafidabd/expense-tracker-cli)

To explore the archive itself:

```bash
git clone https://github.com/Rafidabd/python-phase-1.git
cd python-phase-1
```

The older scripts don't share one common startup command. Open the folder you're interested in and inspect its files before running them.

## Why I've kept this

When I compare the earlier scripts with my newer code, I can see where I started thinking about things like separating modules, checking inputs, saving data, and testing changes. I still have a lot to improve, but I'd rather keep that progression visible than make the whole repository look as though it was written at once.
